# Cuphead 41

A Java bullet-hell game inspired by Cuphead, created for CSCI 41.  
Off branch cuphead

---

# Controls
- `W A S D` → Move
- `Space` → Aim / Shoot
- `T` → Open chat
- `ESC` → Pause / Quit

---

## Gameplay Features
- Bullet-hell combat
- Boss fights with attack patterns
- Loot box / gachapon system
- Random rarity powerups
- Multiplayer support
- In-game text chat
